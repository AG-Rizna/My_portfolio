# A.G. Rizna — Professional Portfolio Website

A responsive, single-page personal portfolio built to showcase my education, skills, projects, certifications and experience as an ICT undergraduate — created as part of the **System Analysis and Design (SAD)** module at the University of Vavuniya.

**Live site:** [insert deployed URL here, e.g. https://ag-rizna.github.io/My_portfolio/]
**SAD report:** see `/docs` or the submitted PDF for the full analysis, design and testing documentation.

---

## ✨ Features

- Responsive navbar with scroll-spy active-link highlighting and a mobile hamburger menu
- Animated hero section with a typewriter-style role display
- About, Education, Skills, Projects, Experience, Certificates, Resume and Contact sections
- Skill proficiency bars grouped by category (Programming, Web, Software Dev, Database, Tools, UI/UX)
- Project cards with tools used, key features and links to GitHub repositories
- Downloadable / viewable CV (PDF)
- Client-side validated contact form
- Scroll-reveal animations and a dark, gradient-accented visual theme

## 🚀 Getting Started Locally

No build tools or dependencies are required — it's a static site.

1. Clone the repository
   ```bash
   git clone https://github.com/AG-Rizna/My_portfolio.git
   cd My_portfolio
   ```
2. Open `index.html` directly in your browser, or serve it locally:
   ```bash
   python3 -m http.server 8000
   ```
3. Visit `http://localhost:8000`
